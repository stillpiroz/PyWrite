# PyWrite

A lightweight rich text editor built with Python and PySide6.

## Features

- Rich text editing
- Bold, italic, and underline formatting
- More features coming soon...

## Requirements

- Python 3.14 or later
- PySide6 6.12.0 or later

## Installation

```bash
git clone https://github.com/stillpiroz/pywrite.git
cd pywrite

uv sync
```

## Usage

```bash
uv run pywrite
```

## Development

PyWrite is currently under active development. Features and functionality may change.
